# ArkDrop

A small self-deployed file transfer assistant.

适合个人在多个设备之间临时分享文字和文件。支持 PWA、图片浏览、收藏和有期限的下载链接。

## 弱网传输

- 文件顺序上传，显示按字节计算的总进度；可收起发送窗口并在站内切换页面。
- 单个文件失败不会删除已完成的文件。重试先查询服务器接收状态，使用稳定的上传标识避免重复创建记录或附件。
- 上传队列保留在当前页面会话中；刷新、关闭页面不会保存待发送文件。当前重试单位为完整文件。
- WebSocket 断线自动重连，恢复联网和回到前台时同步；连续变化通知会合并，连接正常时不定时拉取完整列表。

## 临时缓存

- PWA 图片缓存优先使用本机副本；发送端直接缓存实际上传的图片，避免再次从服务器下载。普通文件不自动预下载或持久缓存。
- 图片缓存上限为 100 MiB，优先淘汰最久未访问的图片。缓存读取时检查记录过期时间，在线同步后清除已删除内容；收藏和未设置过期时间的图片缓存最多保留 24 小时，再次在线同步时可续期。
- 列表元数据最多保留 15 分钟作为离线回退，展示最后同步时间。退出登录会清除 ArkDrop 的列表和图片缓存。
- PWA 新版本手动更新，有待发送内容时不能刷新更新。缓存及过期清理在应用或 Service Worker 运行时执行。

服务启动时会通过现有的 GORM AutoMigrate 给记录及附件添加可空的上传标识和唯一索引，旧记录与不带上传标识的客户端仍可使用。
